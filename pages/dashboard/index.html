渠道

模型协议可按模型名自动识别，也可在已启用模型旁手动切换。新建/编辑渠道点「保存渠道」才写入；列表里启停、删除、复制和优先级会自动保存。启用但没选模型时会自动关掉该渠道。

生图模型优先级

候选范围：有优先级时只用优先级模型，未设置时使用全部启用模型。顺序会依次重试，随机只选一个，固定只用候选模型 1。

审核模型优先级

只控制审核渠道；提示词审核、成品审核按此顺序寻找可用模型。

视频模型优先级

只控制视频渠道；视频生成失败时按此顺序切换。

代理

统一管理 HTTP / SOCKS5 代理。渠道只从已启用列表中选择；连通测试看出口，质量测试探测常用生图站点是否可达。
