# Selfie Image 生图自拍

AstrBot 的生图、图生图、AI 自拍、合影、短视频与管理面板插件。

- 插件名：`astrbot_plugin_selfie_image`
- 当前稳定版：`1.6.15`
- AstrBot：`>=4.13.0,<5`
- 仓库：<https://github.com/liyw0205/astrbot_plugin_selfie_image>

## 功能概览

- 文生图、图生图，以及多张批量生成
- 固定形象自拍、换装、摆姿势、他拍、合影和多人同框
- 文生视频、图生视频、形象视频和视频预设
- 内置提示词预设：`捧脸`、`遮脸`、`变真人`、`变动漫`、`变猫娘`、`变Q版`、`变像素`、`证件照` 等
- 多渠道、多模型、模型优先级、失败回退和任务队列
- 资产库、生成记录、收藏/置顶/标签、历史提示词、重试和画布编排
- 独立 Flask Web 面板与 AstrBot 内嵌 Dashboard
- 图片/视频缓存、SQLite 生成索引、发送状态和缓存清理预览
- 可选提示词审核、出图审核、图片转文字和中英文提示词转换

## 安装

将插件目录放入 AstrBot 的插件目录，目录名建议保持为：

```text
astrbot_plugin_selfie_image
```

在插件目录安装依赖：

```bash
pip install -r requirements.txt
```

依赖包括 `aiohttp`、`aiohttp-socks`、`requests[socks]`、`Flask` 和 `Werkzeug`。

重载或重启 AstrBot 后，插件会加载内置预设并创建插件数据目录。

## 管理面板

### AstrBot 内嵌 Dashboard（推荐）

打开 AstrBot WebUI → 插件 → `Selfie Image 生图自拍` → `dashboard`。

内嵌页跟随 AstrBot 登录态，不需要再次填写插件 Web Token。适合已经运行 AstrBot 面板的部署。

### 独立 Web 面板

插件启动配置只保留 Web 入口：

```yaml
web:
  enable: true
  host: 127.0.0.1
  port: 14514
  token: changeme
```

默认地址：`http://127.0.0.1:14514`。如果需要从其他机器访问，将 `host` 改为实际监听地址，并设置自己的 Token。

`changeme` 仅是占位值；插件启动时会替换为随机 Token 并写入日志。修改 `host`、`port` 或 `token` 后需要重载插件。

面板可以管理：

- 生图、审核和视频渠道，以及模型列表和优先级
- 试画、批量任务、任务取消、重试和任务详情
- 主形象、辅助形象、形象类型（自动/真人/动漫）
- 图片与视频预设、导入导出
- 生成记录和资产库：筛选、分页、收藏、置顶、标签、备注、导出/导入
- 画布：多参考图排序、图生图、模板和结果对比
- 缓存上限、缓存清理预览、权限、额度和审核策略

除 `web` 启动配置外，完整业务配置由面板保存到插件数据目录，不建议手工编辑。

## QQ / 聊天指令

发送 `/生图帮助` 查看图卡，发送 `/生图help` 查看文字帮助。

### 图片

| 指令 | 用途 |
| --- | --- |
| `/画`、`/生图` | 自动判断：有附图或引用图时图生图，否则文生图；不会自动带入形象图 |
| `/文生图` | 只按文字生成；附图不会作为输入，也不会使用形象图 |
| `/图生图` | 必须附图或引用图，按文字修改参考图 |
| `/自拍`、`/看看` | 使用当前形象自拍、换装或摆姿势 |
| `/看看腿` | 成年人物的日常下装穿搭近景；支持预设和额外提示词 |
| `/看看你` | 以他拍视角生成当前形象的日常照片 |
| `/看看COS` | 从内置 COS 池随机换装；可指定角色/类别、`自拍` 或 `他拍`，也可使用 `-c` 和预设 |
| `/合影`、`/合照` | 与用户、@对象或参考图同框；合影只使用主形象图 |
| `/生图模型` | 查看或切换当前会话的生图模型；发送 `清除` 恢复默认 |
| `/生图任务`、`/生图取消` | 查看或取消图片/视频任务，可跟任务号或列表编号 |
| `/查看提示词` | 引用插件生成的图片时查找原提示词；没有记录时由当前聊天 LLM 反推 |
| `/查看生图提示词` | 对附带或引用的图片始终由当前聊天 LLM 反推，不查询插件记录 |
| `/生图重发` | 重发本会话最近一张“已生成但发送失败”的缓存图片 |

数量用 `-c 3` 指定，可放在提示词任意位置；旧写法 `/画 3 ...` 仍兼容。常用参数还包括 `--ar 1:1`、`--resolution 2K`。

```text
/画 一只白猫坐在窗边 --ar 1:1
/画 -c 3 夜晚街头的电影感人像
/图生图 把背景改成海边，并保留人物服装
/自拍 捧脸，看着镜头自然一点 --ar 3:4
/合影 和我一起在咖啡店拍一张
```

### 形象管理

| 指令 | 用途 |
| --- | --- |
| `/形象设置` | 附带或引用图片，设置主形象；也可写 `自动`、`真人`、`动漫` 设置形象类型 |
| `/形象查看` | 查看主形象、形象类型和今日状态 |
| `/形象清除` | 清除主形象参考图 |
| `/形象刷新` | 刷新今日穿搭与自拍设定 |
| `/辅助形象设置` | 添加辅助形象参考图，最多 3 张 |
| `/辅助形象清除` | 清空辅助形象，不影响主形象 |

普通自拍/换装可以使用辅助形象；合影只使用主形象，避免把辅助图误当成合影对象。

### 预设

```text
/预设                         # 查看预设列表
/预设 2                       # 查看第 2 页
/预设添加 电影感:低饱和电影光，浅景深
/预设删除 电影感
/视频预设                     # 查看视频预设
/视频预设 镜头推进             # 使用视频预设
```

图像转换预设需要参考图才有意义，例如 `/图生图 变猫娘` 或在面板试画中选择预设。内置转换预设包括：

`变真人`、`变动漫`、`变猫娘`、`变Q版`、`变像素`、`真人化`、`变COS`、`漫画封面`、`证件照`、`果冻化`。

### 视频

| 指令 | 用途 |
| --- | --- |
| `/视频` | 有图时使用首帧，无图时按文字生成；普通请求不会自动带入形象图 |
| `/文生视频` | 只按文字生成视频 |
| `/图生视频` | 使用附图或引用图作为首帧 |
| `/形象视频`、`/看看视频` | 使用当前主形象图作为首帧 |
| `/视频任务`、`/视频取消` | 查看或取消视频任务 |
| `/视频预设` | 查看、使用和管理视频提示词预设 |

时长可写 `--duration 8`、`--duration=8` 或 `8 秒`，范围为 1–60 秒。

## LLM 工具

启用插件配置中的 LLM 工具后，聊天模型可以调用：

- `generate_image`：普通文生图/图生图
- `generate_selfie`：当前形象自拍、换装、合影和同框
- `generate_video`：文生视频、图生视频或明确要求形象出镜的视频
- `retry_last_generation`：重试最近一次生成

工具路由规则：

1. 普通 `generate_image` 不会因为提示词提到机器人名称就切换为自拍。
2. 普通生图只使用消息中明确附带的参考图，或用户明确引用的上下文图片，不会静默带入主形象图。
3. `generate_selfie` 才会自动携带主形象图；附带图片默认作为服装、姿势、场景或合影对象参考。
4. 用户明确说“自拍、合影、和我一起拍、穿这套、换这身”等关系词时，模型应优先调用 `generate_selfie`。

## 渠道与模型

在面板的“渠道”中添加并启用至少一个图像渠道；视频需要单独配置视频渠道。

常见图像协议：

- `openai`：OpenAI 兼容的 `/images/generations`
- `openai_chat`：只提供 `chat/completions` 的 GPT 生图中继
- `gemini`、`gemini_openai`
- `grok`、`agnes`、`novelai`
- `jimeng2api`、`z_image_gitee`

视频渠道支持 `openai_video`、`sora`、`veo`、`seedance`、`agnes`、`kling`、`cogvideo`、`grok` 等协议族，具体请求格式由模型类型决定。

可配置：

- 多渠道和多模型
- 启用模型优先级
- 调用模式：`sequence`（按顺序）、`random`（随机）、`fixed`（固定首个）
- 全局超时、并发上限、失败回退和批量失败策略
- 每个模型是否先做图片转文字

API Key 会在面板中脱敏保存。不要把真实 Key 写入 README、提交到 Git 或放进前端代码。

## 权限、额度与审核

面板的“权限与限制”可以配置：

- 可使用人员、黑名单、用户白名单和群白名单
- 每日生成次数和请求冷却
- 提示词屏蔽词
- 提示词审核、出图审核、OCR/图片转文字模型
- 中文提示词是否翻译为英文，以及翻译模型

白名单可以按配置不计入每日额度。具体限制以当前面板配置为准。

## 缓存与数据

默认图片缓存上限为 **100 张 / 200 MB**，请求图和生成图共用缓存目录。缓存回收不是“超过数字立即删除全部超出部分”：

- 自动清理只回收较旧、未被生成记录引用的文件
- 生成记录、收藏、置顶或其他资产引用中的媒体会受到保护
- 清理预览显示的是当前可回收数量；显示 `0 张 / 0 MB` 可能表示超限文件仍被记录引用，并不代表统计失败
- 删除资产记录不会在仍有其他记录引用同一文件时删除共享缓存

默认数据位置（相对于 AstrBot 数据目录）：

```text
plugin_data/astrbot_plugin_selfie_image/
├── selfie_image_config.json     # 完整业务配置
├── image_cache/                  # 图片与视频缓存（视频在其 video/ 子目录）
├── generation_records.sqlite3    # 生成记录索引
├── generation_tasks.json         # 任务持久化快照
├── usage_stats.json              # 每日额度统计
├── media_sources/                # 原始媒体来源 sidecar
├── image_presets.json            # 图像预设
├── video_presets.json            # 视频预设
├── image_persona.json            # 主形象元数据
├── image-persona/                # 主形象与辅助形象图片
├── cos_pools.json                # COS 随机池
└── studio_sessions.json          # 画布会话
```

旧版 `generation_records.json` 迁移到 SQLite 时会保留 `.bak` 备份。建议通过面板导出资产元数据，迁移或升级前同时备份整个插件数据目录。

## 任务、记录与发送状态

生成任务会记录来源、提示词摘要、参考图数量、模型尝试、排队进度、成功/失败状态和发送状态。任务中心保留活动任务以及最近 50 条终态任务；生成记录和资产库是更长的持久历史，删除任务元数据不会删除关联生成记录或缓存。

“生成成功”和“发送成功”是两个独立状态：

- 图片已经从上游取得并写入缓存，代表生成成功
- QQ/其他平台消息发送完成，才代表发送成功
- 图片已生成但发送失败时，记录仍保留，可使用 `/生图重发` 或面板中的重试/下载功能

资产库和生成记录使用服务端分页，并缓存相邻页的元数据；切换分页时仍会按权限和 Token 请求媒体内容。
