# AstrBot Selfie Image 生图自拍

给 AstrBot 用的生图与 AI 自拍插件。支持文生图、图生图、固定形象自拍/合影/换装，以及 Web / 内嵌管理面板。

- 当前稳定版：`1.3.95`
- 需要 AstrBot：`>=4.13.0,<5`
- 仓库：https://github.com/liyw0205/astrbot_plugin_selfie_image

1.3.88 增加后台重复请求去重、渠道失败短暂冷却、配置脱敏导入导出、发送失败图片重发（`/生图重发`）、缓存清理预览，并统一 Flask 与 AstrBot 内置 Web 的 Bento Studio 界面。

## 能做什么

- **文生图 / 图生图**：按提示词出图，可附带或引用参考图
- **AI 自拍**：绑定形象参考图后，用当前人设自拍、换装、摆姿势
- **合影同框**：和用户、@对象或参考图一起出镜
- **预设提示词**：如「捧脸」「变真人」「证件照」等，可在指令和面板里选用
- **多渠道出图**：OpenAI 兼容、Gemini、Grok、Agnes、NovelAI 等
- **视频（可选）**：配置视频渠道后可用相关指令
- **管理面板**：独立 Web，或 AstrBot 插件详情里的内嵌 Dashboard

## 安装

1. 把本插件放到 AstrBot 插件目录（目录名建议 `astrbot_plugin_selfie_image`）
2. 安装依赖：

```bash
pip install -r requirements.txt
```

3. 在 AstrBot 插件配置里先设好 Web 入口（启动时读取）：
   - `web.enable`
   - `web.host`
   - `web.port`
   - `web.token`
4. 重载插件，打开管理页，添加并启用至少一个生图渠道
5. 如需固定形象，在面板「形象」里上传参考图，或群里用 `/形象设置` 并附带图片

完整业务配置（渠道、模型、额度、审核等）保存在：

`plugin_data/astrbot_plugin_selfie_image/selfie_image_config.json`

## 管理入口

**独立 Web**

- 默认：`http://127.0.0.1:14514`（以你配置的 `web.port` 为准）
- 配置了 `web.token` 时，打开页面输入 Token
- Token 留空可不校验；占位默认 `changeme` 启动时会换成随机 Token 并写在日志里
- 改 host / port 后需要重载插件

**AstrBot 内嵌页**

- 路径：AstrBot WebUI → 插件详情 → `dashboard`
- 跟随 AstrBot 登录态，不必再输 Web Token
- 与独立 Web 共用同一份配置

面板里可管理：渠道与模型优先级、试画、记录、形象、审核、画布编排、预设等。

## 常用指令

发送 `/生图帮助` 看图卡，`/生图help` 看完整文字说明。

| 指令 | 说明 |
|------|------|
| `/画` 或 `/生图` | 按描述出图；可加数量如 `/画 3`、预设名、`--ar 1:1`、`--resolution 2K` |
| `/文生图` | 提示词尽量直通，少做包装；可写数量 |
| `/图生图` | 带图或引用图，按文字改图；可写数量 |
| `/自拍` 或 `/看看` | 用当前形象自拍；可写动作、场景、换装；支持 `/自拍 捧脸`；可写数量 |
| `/看看腿` | 下半身近景；按姿势搭配光腿神器、白丝或黑丝，可写数量如 `/看看腿 3` |
| `/看看COS` | 随机一套内置 COS 换装；默认随机自拍或他拍，也可写「自拍」「他拍」；可写数量如 `/看看COS 2` |
| `/看看你` | 像别人随手拍你；可写数量 |
| `/合影` 或 `/合照` | 同框合影；可写数量 |
| `/形象设置` | 附带或引用图片，设为 AI 形象 |
| `/形象查看` / `/形象清除` / `/形象刷新` | 查看、清除、刷新今日设定 |
| `/预设` | 查看预设列表；管理员可添加/删除 |
| `/生图模型` | 查看或切换本会话优先模型 |
| `/生图任务` / `/生图取消` | 查看或取消进行中的出图/视频任务 |
| `/视频` / `/图生视频` / `/文生视频` | 需先配置视频渠道；`/视频` 无首帧时使用当前形象图 |

示例：

```text
/画 一只白猫坐在窗边 --ar 1:1
/画 3 一只白猫坐在窗边
/自拍 看着镜头自然一点 --ar 3:4
/自拍 捧脸
/合影 和我一起拍
```

## 对话工具

开启 LLM 工具后，对话里可调用：

- `generate_image`：普通生图
- `generate_selfie`：以当前 AI 形象自拍 / 换装 / 合影

「穿这个」「换这身」并带参考图时，适合走自拍工具：锁身份、迁服装。

## 渠道说明

管理页「渠道」里添加，常见类型包括：

- `openai` / 各类 OpenAI 兼容中转
- `gemini`、`gemini_openai`
- `grok`、`agnes`、`novelai`
- `jimeng2api`、`z_image_gitee` 等

可设多渠道、模型优先级，或随机选用已启用模型；失败时会按策略换渠道继续试（视错误类型而定）。

NovelAI 支持官方接口或兼容网关；视频渠道需单独配置协议/厂商类型。

## 权限与额度

可在面板配置：

- 可使用人员、黑名单
- 白名单用户 / 群（可不计日限）
- 每日次数、请求冷却
- 提示词屏蔽、提示词审核、出图审核等

## 数据位置

均在 AstrBot 数据目录下的插件数据中，例如：

- 配置：`plugin_data/astrbot_plugin_selfie_image/selfie_image_config.json`
- 出图缓存：`.../image_cache`
- 生成记录、形象参考、预设等：同目录下对应文件

缓存超过设定上限时会自动清理较旧文件。
