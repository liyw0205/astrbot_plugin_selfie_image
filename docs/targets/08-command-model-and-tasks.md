# 目标 08：指令侧模型切换与任务查询/取消

## 目标
对齐参考通用生图的「可运营指令面」：用户在会话内可查看/切换模型、查看与取消进行中的生图任务，而不必只依赖 Web。

## 范围
- `/生图模型` 或等价别名：列表、当前、切换（会话或全局策略需在实现时写清并单测）。
- `/生图任务`、`/生图取消`：基于现有 web/后台任务或新会话任务表；权限与会话隔离。
- 帮助文案与失败单因提示更新。
- 不削弱自拍/合影/形象等角色指令。

## 非目标
- 不在本目标重做全部预设系统。
- 不把 Web 管理命令暴露给普通用户。

## 验收
- 帮助列出新指令；切换后下一次 `/画` 或自拍走新模型（行为在文档写死）。
- 取消仅能作用于有权限的任务；查无权限返回单因。
- unittest + 手工烟测通过。

## 验证命令
```bash
python -m unittest tests/test_core.py
# 手工：/生图模型、/生图任务、/生图取消、/画
```

## 风险与回滚
- 风险：全局切换影响多群；优先会话级覆盖。
- 回滚：隐藏命令或配置开关默认关。
