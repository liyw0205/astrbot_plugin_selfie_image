# 目标 13：生图后台化（不阻塞对话）

## 来源
- 市场描述优先补漏：`muyouzhi6/astrbot_plugin_gitee_aiimg`（生图不阻塞对话；LLM 可感知任务）
- `Railgun19457/astrbot_plugin_image_generation` 任务队列
- 调研：`docs/PLUGIN_MARKET_SURVEY.md` B8

## 目标
命令/LLM 触发生图后尽快返回「已受理/任务号」，真正出图在后台完成再推送或可查询，避免长耗时拖死会话事件循环与用户体感「卡死」。

## 范围
- 复用/扩展现有 web 后台 task 模型到命令路径。
- 与目标 08 任务查询/取消对齐。
- 失败单因回传；成功带图。

## 非目标
- 不做跨插件任务总线。
- 不改为必须依赖外部队列中间件。

## 验收
- 触发后数秒内有回执；上游 30s+ 生图期间 bot 仍可处理其他消息（同进程可测事件循环）。
- 任务可查终态。

## 状态
已完成（2026-08-07）：命令生图/自拍先回执任务号，后台 `asyncio.create_task` 推送结果；可 `/生图任务` 查终态。
